I'm a first-year **Software Engineering** student at OSTİM Technical University in Ankara. I want to understand software and systems from the ground up: how they work, how they break, and how to make them secure.

Right now that means building security tooling in Python, from single-purpose utilities to **Argus**, a modular OSINT framework, all with **safe defaults**. The tools use strict input validation, ask for explicit consent before touching a system, and run unit tests in CI. Alongside that, I'm training in penetration testing, web security, and system & network security.

**Long-term goal:** cybersecurity specialist with solid engineering fundamentals.
